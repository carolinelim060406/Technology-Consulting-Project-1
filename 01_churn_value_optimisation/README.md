# Customer Churn & Value Optimisation

## Business Problem
A technology subscription company is facing increased customer churn. The objective of this project is to predict churn risk and translate predictions into value-based retention recommendations.

## Techniques Used
- Pandas feature engineering
- Exploratory data analysis
- Logistic Regression (baseline)
- Random Forest
- Gradient Boosted Decision Trees
- Confusion Matrix & ROC-AUC evaluation
- Value-based prioritisation

## Key Insights
- Ensemble models significantly outperform linear baselines
- Churn risk alone is insufficient — combining risk with customer value enables better targeting
- Interpretability-performance trade-offs must be managed in consulting contexts

## Relevance to Technology Consulting
This project reflects real-world consulting engagements involving customer analytics, decision support systems, and stakeholder-driven trade-offs between accuracy, explainability, and business value.
